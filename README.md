# Buildathon Radar

A static intelligence site built from a live scrape of Akindo's public API (2026-09-23).
No build step, no framework — plain HTML/CSS/JS with the datasets in `data/`.

## Sections
1. **Latest buildathon** — Build Privacy-First Apps on Midnight: rubric, pools, 159 Wave-1 submissions, quality signals, and the named project lists behind every stat (near-empty updates, deliverable URLs, repos, threads, themes).
2. **EVM Explorer** — EVM projects by submission count (search, chain/category filters, submission counts, chain distribution, Mezo-relevant slice sizes).
3. **Env Catalog** — the environmental/ReFi projects with submission history.
4. **Mezo Plan** — the Mezo Buildathon ($7,000 in MEZO, two waves): timeline, rubric, payout mechanics (KYB + 14-day TWAP explained), and six scored project ideas.
5. **Collisions** — the Veilpay/Vielpay/veil-pay lookalike-name warning.

## Files
- `index.html`, `assets/styles.css`, `assets/app.js` — the site
- `data/*.json` — datasets powering the site (EVM file contains the top projects by submission count; the full 2,381-row dataset is generated by re-running the skill's scrape pipeline)
- `akindo-buildathon-analysis.md`, akindo-evm-mezo-brief.md`, `mezo-buildathon-plan.md` — the written analysis and participation plan
- `.agents/skills/akindo-buildathon-research/SKILL.md` — the reusable research skill built during this work

## Run locally
```
python3 -m http.server 4321
# open http://localhost:4321
```

## Deploy
Static site — drag the folder onto vercel.com/new, or `npx vercel deploy --prod` from your own terminal.

*Not affiliated with Akindo or Mezo. All figures are raw counts from the public API at scrape time.*
